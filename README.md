# The Last Interface Engineer

The source for [Aakash Suresh's portfolio](https://aakash-suresh.vercel.app): an editorial, motion-led showcase of production engineering experience and independently built AI tools.

## Featured work

- **AgentFlow** — a multi-agent orchestration harness with parallel specialists, persistent memory, scheduling, and four LLM providers.
- **Figma i18n MCP** — an MCP server that turns visible Figma copy into structured, translation-ready JSON.
- **AI Context Sentinel** — a local context layer for keeping Cursor and Claude Code aligned with a repository.
- **wrap-it** — a published npm CLI that turns Git history into an annual engineering report.
- **Friendly Neighbourhood** — a realtime, geospatial mobile product with KYC flows and PII masking.

## Stack

Next.js 16, React 19, TypeScript, Tailwind CSS 4, and Motion.
